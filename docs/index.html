MulRan 원본 구조

MulRan sequence 폴더 하나를 dataloader_convert.py --source로 넘깁니다.

<mulran_sequence>/
  sensor_data/
    data_stamp.csv
    gps.csv
    xsens_imu.csv
    Ouster/
      <timestamp_ns>.bin
    radar/
      polar/
        <timestamp_ns>.png
  global_pose.csv
Path용도
sensor_data/data_stamp.csv<timestamp_ns>,<sensor_name> 형식의 timeline입니다.
sensor_data/Ouster/*.binOuster LiDAR scan입니다. x,y,z,intensity float32를 읽고 ring을 계산합니다.
sensor_data/radar/polar/*.pngNavtech radar polar image입니다. local dataset의 radara/polar 폴더도 허용합니다.
sensor_data/gps.csvNavSatFix publish에 사용하는 GPS row입니다.
sensor_data/xsens_imu.csvImu, optional MagneticField publish에 사용하는 Xsens row입니다.
global_pose.csv있으면 converter가 poses/gt.tum으로 저장합니다.
timeline에 sensor label이 있어도 실제 sensor 폴더가 없으면 converter는 실패하지 않고 해당 sensor를 converted manifest에서 제외합니다.

HeLiPR 원본 구조

HeLiPR sequence 폴더 하나를 dataloader_convert.py --source로 넘깁니다.

<helipr_sequence>/
  stamp.csv
  Inertial_data/
    inspva.csv
    xsens_imu.csv
  LiDAR/
    Ouster/
      <timestamp_ns>.bin
    Velodyne/
      <timestamp_ns>.bin
    Avia/
      <timestamp_ns>.bin
    Aeva/
      <timestamp_ns>.bin
  LiDAR_GT/
    Ouster_gt.txt
    Velodyne_gt.txt
    Avia_gt.txt
    Aeva_gt.txt
    global_Ouster_gt.txt
Path용도
stamp.csv<timestamp_ns>,<sensor_name> 형식의 timeline입니다.
Inertial_data/inspva.csvnovatel_gps_msgs/Inspva publish에 사용합니다.
Inertial_data/xsens_imu.csvImu, optional MagneticField publish에 사용합니다.
LiDAR/Ouster/*.binOuster scan입니다.
LiDAR/Velodyne/*.binVelodyne scan입니다.
LiDAR/Avia/*.binLivox Avia scan입니다. playback 시 livox_ros_driver message가 필요합니다.
LiDAR/Aeva/*.binAeva scan입니다.
LiDAR_GT/*_gt.txt있으면 converter가 LiDAR별 TUM pose로 저장합니다.
local dataset의 Oustera, Velodynea, Aviaa, Aevaa 폴더명도 허용합니다.
livox_avia를 재생하려면 /home/beom/livox_ws/devel/setup.zsh 또는 setup.bash를 source해서 livox_ros_driver가 ROS 환경에 잡혀 있어야 합니다.
