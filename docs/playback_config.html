Playback Config 설명

config/mulran.yaml, config/helipr.yaml, config/semantic_kitti.yaml에서 자주 바꾸는 값과 optional override를 정리했습니다.

원본 dataset 배치 Convert 최종 구조 Playback Config

기본 실행

source /opt/ros/noetic/setup.zsh
source /home/beom/dynamic_ws/devel/setup.zsh

roslaunch dataloader player.launch \
  config:=$(rospack find dataloader)/config/mulran.yaml

HeLiPR에서 livox_avia: true를 켤 때는 Livox message가 필요합니다.

source /home/beom/livox_ws/devel/setup.zsh
MulRan만 재생하거나 HeLiPR에서 livox_avia: false를 유지한다면 Livox workspace source는 필요하지 않습니다.

최소 Config 구조

config 파일에는 자주 바꾸는 값만 남겼습니다. topic 이름, frame id, transform 세부값은 player 기본값을 사용합니다.

data_root: /data/converted_datasets
dataset: helipr
sequence: DCC01

play_rate: 1.0
loop: false

primary_lidar: ouster
start_lidar_frame: 0
end_lidar_frame: -1

publish:
  inspva: true
  imu: true
  imu_mag: false
  ouster: true
  velodyne: false
  livox_avia: false
  aeva: false

transform:
  enabled: false
Key설명
data_root<data_root>/<dataset>/<sequence>/manifest.yaml를 찾습니다.
play_rate1.0은 real-time, 2.0은 2배속입니다.
looptrue이면 선택 구간을 반복 재생합니다.
primary_lidarframe index 구간을 정할 기준 LiDAR입니다.
start_lidar_frame, end_lidar_frame0-based LiDAR frame index입니다. end_lidar_frame: -1은 마지막 frame까지 재생합니다.
publishtopic별 publish 여부입니다. 센서 선택은 string list가 아니라 true/false로 관리합니다.

HeLiPR livox_avia publish는 livox_ros_driver/CustomMsg를 사용하므로 Livox workspace를 source해야 합니다.

Optional Override

topic 또는 frame id를 바꾸고 싶을 때만 아래 block을 config에 추가합니다.

topics:
  ouster: /ouster/points
  livox_avia: /avia/points

frame_ids:
  ouster: ouster
  livox_avia: livox_avia

/clock은 기본 publish됩니다. 끄고 싶으면 기존 publish block 안에 추가합니다.

publish:
  clock: false
  ouster: true

Pose Transform Playback

SLAM을 새로 돌릴 때는 transform.enabled: false로 raw LiDAR frame을 그대로 쓰면 됩니다. 이미 구한 SLAM pose, GT pose, submap 정합 matrix를 playback에 반영할 때만 켭니다.

transform:
  enabled: true
  pose_source: custom
  pose_file: /path/to/poses.txt
  static_matrix_file: /path/to/submap_transform.txt
  output_frame_id: map
  publish_pose: true

converter가 저장한 GT pose를 쓰려면 직접 file path를 쓰지 않아도 됩니다.

transform:
  enabled: true
  pose_source: gt
  output_frame_id: map
Option기본값설명
pose_sourcecustomcustom, gt, gt_global 중 선택합니다.
pose_fileemptycustom일 때 읽을 TUM pose file입니다.
pose_timestamp_tolerance_ns50000000sensor timestamp와 pose timestamp의 최대 허용 차이입니다.
static_matrix_fileemptysubmap 정합 등에 쓰는 4x4 matrix txt file입니다.
static_transform_orderafter_poseafter_pose: T_static * T_pose, before_pose: T_pose * T_static
apply_to_pointcloudtrueLiDAR point의 x,y,z에 transform을 적용합니다.
publish_posefalse계산된 pose를 PoseStamped로 함께 publish합니다.
pose_topic/dataloader/posepublish_pose: true일 때 사용할 topic입니다.
 
# TUM pose
timestamp tx ty tz qx qy qz qw

# 4x4 matrix txt
r00 r01 r02 tx
r10 r11 r12 ty
r20 r21 r22 tz
0   0   0   1
