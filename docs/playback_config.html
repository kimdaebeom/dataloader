Playback Config 설명

config/mulran.yaml, config/helipr.yaml, config/semantic_kitti.yaml에서 자주 바꾸는 값과 optional override를 정리했습니다.

start paused spacebar control one-line progress

기본 실행

playback은 raw dataset이 아니라 convert가 끝난 <converted_root>/<dataset>/<sequence>를 읽습니다. 먼저 config의 data_root, dataset, sequence가 변환 결과 위치와 맞는지 확인합니다.

source /opt/ros/noetic/setup.zsh
source /home/beom/dynamic_ws/devel/setup.zsh

roslaunch dataloader player.launch \
  config:=$(rospack find dataloader)/config/mulran.yaml

HeLiPR에서 livox_avia: true를 켤 때는 Livox message가 필요합니다.

source /home/beom/livox_ws/devel/setup.zsh
MulRan만 재생하거나 HeLiPR에서 livox_avia: false를 유지한다면 Livox workspace source는 필요하지 않습니다.
Space재생 / 정지시작 직후에는 pause 상태입니다.
q종료터미널에서 playback을 종료합니다.
bar진행률맨 아래 한 줄만 최신 상태로 갱신됩니다.

최소 Config 구조

config 파일에는 자주 바꾸는 값만 남겼습니다. topic 이름, frame id, transform 세부값은 player 기본값을 사용합니다.

data_root: /data/converted_datasets
dataset: helipr
sequence: DCC01

play_rate: 1.0
loop: false
keyboard_control: true
start_paused: true

primary_lidar: ouster
start_lidar_frame: 0
end_lidar_frame: -1

publish:
  inspva: true
  imu: true
  imu_mag: false
  ouster: true
  velodyne: false
  livox_avia: false
  aeva: false

transform:
  enabled: false
Key설명
data_root<data_root>/<dataset>/<sequence>/manifest.yaml를 찾습니다.
play_rate1.0은 real-time, 2.0은 2배속입니다.
looptrue이면 선택 구간을 반복 재생합니다.
keyboard_controltrue이면 terminal spacebar로 pause/resume을 제어합니다.
start_pausedtrue이면 시작 직후 멈춘 상태로 대기합니다. spacebar를 눌러 재생합니다.
primary_lidarframe index 구간을 정할 기준 LiDAR입니다.
start_lidar_frame, end_lidar_frame0-based LiDAR frame index입니다. end_lidar_frame: -1은 마지막 frame까지 재생합니다.
publishtopic별 publish 여부입니다. 센서 선택은 string list가 아니라 true/false로 관리합니다.

Optional Override

topic 또는 frame id를 바꾸고 싶을 때만 아래 block을 config에 추가합니다.

topics:
  ouster: /ouster/points
  livox_avia: /avia/points

frame_ids:
  ouster: ouster
  livox_avia: livox_avia

/clock은 기본 publish됩니다. 끄고 싶으면 기존 publish block 안에 추가합니다.

publish:
  clock: false
  ouster: true

터미널 출력

player는 시작할 때 핵심 정보만 간단히 출력합니다. 재생 중에는 한 줄 progress bar가 계속 덮어써지며 최신 상태만 보이도록 동작합니다.

dataloader playback
mulran/DCC01 | copy | rate 1x | loop False
66205 events | lidar ouster:0-5541 (5542/5542) | 554.1s | clock on | tf off
sensors: gps, imu, ouster, radar | topics: gps:/gps/fix, imu:/imu/data_raw, ouster:/os1_points

play [##############--------------]  50.0% | ev 33103/66205 | lidar 2771/5542 | t+277.0s | imu | pub 33103

출력 주기를 바꾸고 싶으면 config에 아래 optional 값을 추가합니다.

기본값은 start_paused: true입니다. 시작 후 spacebar를 눌러 재생하고, 다시 spacebar를 누르면 pause됩니다. q는 종료입니다. terminal 입력을 잡을 수 없는 환경에서는 자동 재생으로 fallback됩니다.
Key기본값설명
progress_log_interval_sec2.0이 시간 이상 지나면 진행 상태를 출력합니다. 0이면 시간 기준 출력을 끕니다.
progress_log_percent_step5.0event 진행률이 이 값 이상 증가하면 출력합니다. 0이면 percent 기준 출력을 끕니다.
progress_bar_width28progress bar 길이입니다.
terminal_colortrueANSI color 출력 여부입니다.
terminal_direct_ttytrue가능하면 ROS log pipe가 아니라 현재 terminal에 직접 progress line을 씁니다.
 
progress_log_interval_sec: 2.0
progress_log_percent_step: 5.0
progress_bar_width: 28
terminal_color: true
terminal_direct_tty: true

Pose Transform Playback

SLAM을 새로 돌릴 때는 transform.enabled: false로 raw LiDAR frame을 그대로 쓰면 됩니다. 이미 구한 SLAM pose, GT pose, submap 정합 matrix를 playback에 반영할 때만 켭니다.

transform:
  enabled: true
  pose_source: custom
  pose_file: /path/to/poses.txt
  static_matrix_file: /path/to/submap_transform.txt
  output_frame_id: map
  publish_pose: true

converter가 저장한 GT pose를 쓰려면 직접 file path를 쓰지 않아도 됩니다.

transform:
  enabled: true
  pose_source: gt
  output_frame_id: map
Option기본값설명
pose_sourcecustomcustom, gt, gt_global 중 선택합니다.
pose_fileemptycustom일 때 읽을 TUM pose file입니다.
pose_timestamp_tolerance_ns50000000sensor timestamp와 pose timestamp의 최대 허용 차이입니다.
static_matrix_fileemptysubmap 정합 등에 쓰는 4x4 matrix txt file입니다.
static_transform_orderafter_poseafter_pose: T_static * T_pose, before_pose: T_pose * T_static
apply_to_pointcloudtrueLiDAR point의 x,y,z에 transform을 적용합니다.
publish_posefalse계산된 pose를 PoseStamped로 함께 publish합니다.
pose_topic/dataloader/posepublish_pose: true일 때 사용할 topic입니다.
 
# TUM pose
timestamp tx ty tz qx qy qz qw

# 4x4 matrix txt
r00 r01 r02 tx
r10 r11 r12 ty
r20 r21 r22 tz
0   0   0   1
