Convert 최종 Format 구조

raw dataset을 dataloader가 공통으로 읽을 수 있는 구조로 정리했을 때의 결과물입니다.

원본 dataset 배치 Convert 최종 구조 Playback Config

최종 Folder Layout

<converted_root>/
  <dataset>/
    <sequence>/
      manifest.yaml
      timeline.csv
      sensors/
        lidar/
          <lidar_name>/
            <timestamp_ns>.bin
        imu/
          xsens_imu.csv
        gps/
          gps.csv
        inertial/
          inspva.csv
        radar/
          polar/
            <timestamp_ns>.png
      poses/
        gt.tum
        gt_ouster.tum
        gt_global_ouster.tum

reference mode에서는 sensor file을 복사하지 않고 manifest.yaml에 원본 absolute path를 저장합니다. 그래도 player와 offline algorithm은 같은 timeline.csv와 manifest.yaml을 기준으로 읽으면 됩니다.

manifest.yaml

dataset 이름, sequence 이름, 사용 가능한 sensor, 기본 topic, frame ID, primary LiDAR, pose file 위치를 기록합니다.

dataset: helipr
sequence: KAIST05
primary_lidar: ouster
timeline: timeline.csv
sensors:
  ouster:
    kind: pointcloud
    format: helipr_ouster
    topic: /ouster/points
    frame_id: ouster
  livox_avia:
    kind: livox_custom
    format: helipr_livox_avia
    topic: /avia/points
    frame_id: livox_avia
poses:
  gt:
    default: poses/gt_ouster.tum
    ouster: poses/gt_ouster.tum
    livox_avia: poses/gt_livox_avia.tum
  gt_global:
    default: poses/gt_global_ouster.tum
    ouster: poses/gt_global_ouster.tum

timeline.csv

모든 dataset은 아래 공통 형식으로 정렬됩니다.

timestamp_ns,sensor,relative_path
1690000000000000000,ouster,sensors/lidar/ouster/1690000000000000000.bin
1690000000010000000,imu,sensors/imu/xsens_imu.csv

player는 primary_lidar의 frame index로 시간 구간을 정한 뒤, 그 시간 범위 안에 들어오는 enabled sensor event만 publish합니다.

Pose 저장 규칙

원본 dataset에 GT pose가 있으면 converter가 TUM format으로 poses/ 아래에 저장합니다.

Dataset원본변환 결과
MulRanglobal_pose.csvposes/gt.tum, poses.gt, poses.gt_global
HeLiPRLiDAR_GT/Ouster_gt.txt 등poses/gt_ouster.tum 등 LiDAR별 pose
HeLiPR globalLiDAR_GT/global_Ouster_gt.txt 등poses/gt_global_ouster.tum 등 LiDAR별 global pose
 
timestamp tx ty tz qx qy qz qw
timestamp는 seconds 또는 nanoseconds를 허용합니다. converter가 저장하는 값은 nanoseconds 기준입니다.

Storage Mode

Mode동작권장 상황
referencemetadata만 저장하고 원본 file absolute path를 참조합니다.기본값, 용량 최소화
symlink통일된 폴더 구조에 symlink를 만듭니다.filesystem이 symlink를 지원할 때
hardlinkhardlink를 생성합니다.같은 filesystem 안에서 중복 저장을 피할 때
hardlink_or_copyhardlink 실패 시 copy합니다.portable한 결과물이 필요할 때
copysensor file을 모두 복사합니다.원본 dataset 없이 독립 보관할 때

Convert 명령어

rosrun dataloader dataloader_convert.py \
  --dataset mulran \
  --source /media/beom/ux_dataset1/dataset/mulran/KAIST01 \
  --output /media/beom/ux_dataset1/dataset/converted \
  --sequence KAIST01
rosrun dataloader dataloader_convert.py \
  --dataset helipr \
  --source /media/beom/ux_dataset1/dataset/helipr/KAIST05 \
  --output /media/beom/ux_dataset1/dataset/converted \
  --sequence KAIST05 \
  --start-lidar-frame 100 \
  --end-lidar-frame 200
